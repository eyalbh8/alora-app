Verifying the round trip

  • Open DevTools → Network and filter for track. A tagged reload should show one POST.
  • The tracker is silent by design, so no console output means it either fired or opted out. Use the banner above to tell which.
  • Confirm the row landed: SELECT provider, source, path, timestamp FROM analytics_events ORDER BY timestamp DESC LIMIT 10;
  • Referrer-based detection cannot be simulated by editing the URL; it needs a real click-through from an AI chat interface.
